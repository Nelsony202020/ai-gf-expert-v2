OurDream AI has one of the best AI image generators I’ve tested so far, but the first time I opened it, I had no idea what I was looking at.

There are different image models, presets, settings, Free Play, Remix, editing tools, and a bunch of other options. It looks complicated, but once you understand what each part does, it’s actually pretty easy to use.

This is the ultimate OurDream AI image generator guide for beginners. I’ll show you how the OurDream AI image generator works, which model to use, how to generate your first images, how presets work, and what to do when the result isn’t right.

If you already know the basics, you can skip this guide and go straight to my more advanced OurDream AI image prompt guide. I’ll also cover NSFW generation, character consistency, and editing in separate guides as those go live.

How to Open the OurDream AI Image Generator

To open the OurDream AI Image Generator, navigate to the Generate button in the sidebar.

Character Mode vs Free Play

Before you generate an image, you need to pick a character. You can pick from:

  1. A character you created
  2. A character from the public library
  3. A Free Play character

Generate Images With an Existing Character

Generating images with an existing character is great if you want consistent images. Keep in mind that OurDream AI only looks at the first image; they don’t use character LoRAs.

So the first image of the character matters a lot. If that image involves multiple people or is far away, OurDream may have a very hard time generating consistent images later.

Generate Images With Free Play

Free Play lets you generate all sorts of images without being tied to a specific character. It’s important that you select the right Free Play option. If you want to generate a single female, select female; for a single male, select male.

Choose Your Image Generator

OurDream AI currently has three image generators: Dreamy, Vivid, and Vivid 2. They can all generate images, but they work a bit differently. There is no single model that is always the best.

Dreamy

Dreamy is OurDream AI’s own image generator.

The main reason to use Dreamy is porn. It is good at generating nude images and sexual poses.

The trade-off is that the rest of the image can sometimes be less impressive. Things like the background, clothing, furniture, and lighting may look more basic.

Dreamy also works better with keyword-based prompting instead of writing a long natural sentence.

For example, instead of:

She is sitting at a beach wearing a black dress while the sun is setting behind her.

You could write something more like:

sitting, beach, black dress, sunset, warm lighting, front view

So if your main goal is generating porn, Dreamy is usually the first model I would try.

Vivid

Vivid is better suited to more normal scenes where the whole image matters.

For example, if you care about the clothing, environment, pose, lighting, and what is happening in the scene, Vivid can be easier to work with.

Another big difference is prompting. Vivid can understand more natural descriptions, so you don’t always have to write everything as a list of short tags.

For example:

She is sitting at a beach during sunset wearing a black dress and looking toward the camera.

That type of prompt makes more sense with Vivid than with Dreamy.

The original Vivid is not as good as Dreamy for generating explicit porn, especially when you need visible sexual details.

Vivid 2

Vivid 2 is the newer Vivid model.

I have used it with long and detailed prompts, and it can understand much more detailed descriptions.

However, I have not tested Vivid 2 enough against Dreamy and the original Vivid to confidently tell you exactly what it is best at yet. I don’t want to make up a recommendation just because it is the newer model. I will update this section once I have tested all three properly side by side.

Which Image Generator Should You Use?

The easiest way to look at it for now is:

  • Dreamy — use it when your main goal is generating porn or explicit sexual images.
  • Vivid — use it when you care more about the full scene, such as clothing, poses, backgrounds, and lighting. It also works better with normal written descriptions.
  • Vivid 2 — the newer option. It can handle detailed prompts well and is also good at NSFW. That said, I still need to test it more before I can say exactly when you should choose it over Dreamy or Vivid.

If you are not sure, just try the same idea with two different models. Changing the image generator can sometimes make a bigger difference than rewriting your prompt over and over.

How to Generate an Image

Once you open the image generator, there are a few different ways to build your image. You can keep it very simple and write everything yourself, or use OurDream’s presets to help with the pose, outfit, and scene.

Choose a Character or Use Free Play

The first choice is whether you want to generate an image of one of your existing characters or use Free Play.

If you select a character, OurDream already knows what that character should look like. You mainly need to tell it what you want the character to be doing.

Free Play works differently. You are not using one of your saved characters, so you have more freedom to create the image from scratch.

I mostly use Free Play when I want to test prompts or create something without worrying about keeping an existing character consistent.

Add a Pose, Outfit, and Scene

You don’t have to describe everything yourself. OurDream has presets for:

  • Pose
  • Outfit
  • Scene

Each one is optional. For example, you could select Pose: Standing, Outfit: College Uniform, Scene: Beach. You can also leave any of them empty and describe what you want in the custom prompt instead.

There are a lot of presets available. The Pose library includes everything from normal standing poses to NSFW poses and even porn. The Outfit library includes things like uniforms, lingerie, and other clothing, while the Scene library includes places like bedrooms, hotels, beaches, pools, and offices.

There are also community presets and your own saved presets.

I am still testing how useful the preset system is compared with writing everything yourself, so I am not going to go too deep into creating custom presets in this guide.

Write a Custom Prompt

Below the presets is the Custom Prompt field. This is where you can give OurDream extra instructions about what you want to see.

For example:

sitting on the beach, black dress, sunset, looking at camera, warm lighting

You can use the custom prompt together with presets. So you could select a Beach scene and then use the prompt to add more details about the lighting, pose, or camera angle.

You can also skip the presets completely and describe the whole image yourself.

For this guide, I am only covering the basics. If you want to learn about prompt structure, clothing, poses, camera angles, weights, and other prompting tricks, I cover those separately in my OurDream AI Image Prompt Guide.

Choose Your Image Settings

Click Settings to change how the image is generated. There are a few important options.

Image generator. You can choose between Dreamy, Vivid 1.0, and Vivid 2.0. Dreamy is currently the default. As I explained above, the best model depends on what you are trying to generate.

Aspect ratio. You can choose 4:5 Portrait, 5:4 Landscape, 9:16, 16:9, or 1:1. I normally use a vertical ratio like 4:5 or 9:16 for images focused on one character. Landscape makes more sense when the environment is an important part of the image.

Keep in mind that most image generators are trained on 1:1, 4:5, and 9:16. So if you try to generate a character image that’s landscape, results are often lower quality.

Number of images. The current options go from 2 all the way up to 256 images. I don’t think you need to generate a crazy amount when you are just starting. Generating a few versions first makes it much easier to see if your idea and prompt actually work. If they don’t, fix the problem before generating another huge batch.

Add a Negative Prompt

There is also a Negative Prompt field inside Settings.

This works the opposite way from your normal prompt. Your normal prompt tells OurDream what you want. The negative prompt tells it what you don’t want.

For example, if the generator keeps adding something you don’t want in the image, you can try adding it to the negative prompt.

You don’t always need to use this. I would only start adding negative prompts when you actually have a problem you are trying to fix.

Generate a Few Images First

Once everything is ready, hit Generate. I recommend starting with a small batch instead of generating dozens of images immediately. Then look at the results.

Don’t only ask: is this image good or bad? Look at what is actually wrong. Maybe:

  • the pose is wrong
  • the outfit is wrong
  • the background is wrong
  • the camera angle is wrong
  • the character looks different
  • the model misunderstood part of your prompt

This makes it much easier to know what to change next.

Change One Thing at a Time

This is probably the most useful habit I have learned while testing AI image generators.

If the result is already 80% correct, don’t completely rewrite your prompt. Change the part that is wrong and generate again.

If the pose is wrong, fix the pose. If the clothing is wrong, fix the clothing. If the image looks good but the background sucks, don’t start from zero.

Changing five things at once makes it very hard to know which change actually helped.

The goal isn’t to write the perfect prompt before you generate anything. Start simple, look at what OurDream gives you, and improve it from there.

Image Editing

One of the most useful features in OurDream AI is the Image Editor.

It is great when you generate an image you already like, but there is one small thing you want to change. Instead of generating the whole image again, you can edit the image you already have.

Simply click on one of your generated images and choose Edit Image. Then type what you want to change and hit Generate.

For example, if I like the image but want to change the dress from black to red, I can simply ask OurDream to make the dress red.

There is also a second way to edit an image called Inpainting. With Inpainting, you brush over the exact part of the image you want to change. Your prompt will then mainly apply to that selected area instead of the whole image.

So if I wanted to change the dress to red, I would brush over the dress and use the same prompt.

From my experience, Inpainting is usually more accurate when you only want to change one specific part of an image. If the image is already close to what you want, I would normally try editing or inpainting before generating everything again from scratch.

How to Write a Basic Image Prompt

You do not need to make your first prompt complicated. A good beginner prompt should simply describe what you want to see in the image.

I usually think about it like this:

subject → pose/action → clothing → location → lighting → camera angle

For example:

woman sitting on the beach, black dress, sunset, looking at camera, warm lighting, medium shot

That is already enough to give the image generator a clear direction. You can always add more detail later if something is missing.

I would not start by adding a ton of weights, brackets, or advanced prompt tricks. First generate a few images and see what OurDream gets right and what it gets wrong.

If you want to go deeper into clothing prompts, poses, lighting, camera angles, prompt weights, and negative prompts, I cover all of that in my OurDream AI Image Prompt Guide.

What Are OurDream AI Presets?

OurDream AI also has a preset system that lets you build part of the image without writing everything yourself. You can choose presets for pose, outfit, and scene. You can use one preset, combine multiple presets, or skip them completely and write everything in the custom prompt field.

Using a Preset

Using a preset is the easiest option if you already see something close to what you want. For example, you could choose a standing pose, a specific outfit, and a beach scene. Then use the custom prompt field to add extra details such as the lighting, camera angle, or expression.

OurDream also has a large preset library with presets made by the platform and the community. This is especially useful if you do not know how to describe a certain pose or scene yourself.

Creating Without a Preset

You do not have to use presets. You can leave the pose and scene empty and describe everything yourself in the Custom Prompt field. This gives you more control, but it also means you need to be more specific about what you want.

I personally like testing both methods. Sometimes a preset gets you close very quickly, while other times writing the scene yourself gives you better control.

Custom Presets

OurDream also lets users create their own presets and save them for later. There are custom presets for things like poses, outfits, and scenes, and users can also browse community-made presets.

I have not tested the custom preset system enough yet to tell you the best way to create or use them, so I am not going to pretend I have a full strategy for it.

For now, I would treat custom presets as an optional tool. You do not need them to create good images, and you can always generate everything using the normal prompt field.

How Remix Works

Remix is useful when you already generated an image you like, but you want to try a different version of it without starting completely from scratch.

The main thing to understand is that Remix uses the same image generator again. So if the original image was made with Dreamy, Vivid, or Vivid 2, Remix takes that image and lets you prompt it again using that same type of generation.

This is different from Edit Image, which uses one of OurDream’s editing engines, such as Spark or Fusion, to change the existing image.

Where to Find Remix

Open one of your generated images and look for the Remix option. From there, you can see the prompt used for the image, make changes, and generate a new version.

This can be useful if you like the general result but want to try things like a different pose, a different expression, a slightly different scene, or changes to the prompt.

When I Would Use Remix

I would mainly use Remix when I like the general direction of an image and want another version of it. For example, maybe the character looks good, and the scene is close, but you want to change the pose or adjust part of the prompt. Instead of going back and building the image again from zero, Remix gives you a quicker starting point.

Remix vs Generating Again

Generating again from the main image generator means you are basically starting a new generation using your current setup. Remix is supposed to make it easier to build from an image you already made.

However, I have had mixed results with it recently. A few weeks ago, Remix worked better for me. More recently, I noticed that some custom information does not always carry over properly.

For example, when I tested one of my own presets, Remix kept the character and the general setting, but it did not properly keep the custom outfit. Some of the information that appeared in the prompt also did not match the outfit I originally used.

Because of that, I currently do not rely on Remix when I need very specific clothing, backgrounds, or custom preset details to stay the same.

Remix vs Edit Image

This is the important difference:

  • Remix uses the image generator again to create a new version of the image.
  • Edit Image uses an editing model like Spark or Fusion to directly change the existing image.

If I already like the image and only want to change one specific thing, I normally prefer Edit Image or Inpainting. If I want a new version of the same general idea, Remix can still be useful.

How In-Chat Image Generation Works

Another way to generate images in OurDream AI is directly inside the chat. This is much more basic than the main image generator, but it is also very easy to use.

Inside the chat bar, click the icon in the bottom left and switch to Image. Then just describe what you want and generate it.

The nice part is that you do not need to write a super-structured prompt here. You can just talk normally and say what you want to see.

From my experience, this works surprisingly well. It is fast, easy to use, and much better than a lot of competitors. For example, Candy AI often gives more random results, while OurDream AI usually understands the request better.

The downside is that you do not get much control. You cannot use presets here like you can in the main generator, so this is more for convenience than deep customization.

Giving the Chat More Direction

The chat image tool works best when you are clear and direct. You can say simple things like:

  • send me a picture of you at the beach
  • show me what you look like in a red dress
  • send a selfie in your bedroom
  • show me at university

You can also talk in a normal way and build on the roleplay. That is actually one of the best things about it. If you are chatting and roleplaying, image generation feels very natural here. You do not need to leave the conversation and start setting up a full prompt somewhere else.

Another great feature is contextual images.

For example, if you are roleplaying that the character is at a university, you can often just use the image option and have her send a picture in that setting. That makes the conversation feel a lot more immersive. You can also make follow-up requests if the first image is not exactly what you want. Just tell the chat what to change.

When to Use the Main Generator Instead

The chat image generator is great when you want something fast, simple, and natural. I would use it when you want a quick image during a chat, you want the conversation to feel more immersive, you want to describe things in normal language, or you do not need a lot of control.

I would switch to the main generator when you want more control over the result. For example, use the main generator if you want presets, more image settings, more control over the prompt, more repeatable results, or more serious testing.

So basically: use chat image generation for convenience. Use the main generator for control.

Also, after generating an image in chat, you can do more with it. You can click the pencil icon to edit the image, and you can also turn images into videos.

My Recommended OurDream Image Workflow

After testing OurDream for a while, I think the easiest way to get good results is to keep things simple at the start and only add more detail when you actually need it.

  1. Start with a character or Free Play. If I want an image of an existing character, I select that character. If I just want to test an idea or create something completely new, I use Free Play.
  2. Choose the right image generator. If my main goal is porn, I usually start with Dreamy. For more normal scenes where the clothing, background, and overall image matter more, Vivid can be easier to work with. I am still testing Vivid 2, so I usually just try it when I want to compare the result with the other models.
  3. Start with a simple prompt. I wouldn’t start with a giant prompt. Give OurDream the main idea first — for example, woman sitting at a beach, black dress, sunset, looking at camera. Generate a few images and see what happens. You can always make the prompt more detailed later.
  4. Generate a few results. AI image generation has a lot of randomness. One bad image doesn’t automatically mean your prompt is bad. I normally generate a few results first so I can see if OurDream understands the general idea.
  5. Pick the image closest to what you want. Don’t look for perfection immediately. I usually pick the image that is closest to what I had in mind. Maybe the character, pose, and background are already good, but the dress is the wrong color. That is much easier to fix than starting over completely.
  6. Fix one thing at a time. If an image is 80% right, don’t rewrite the entire prompt. Change the part that is wrong.
  7. Edit instead of starting over. Once I have an image I really like, I usually stop generating completely new images. If I only need to change something small, I use Edit Image or Inpainting. I use Remix more when I want another version of the same general image, but I don’t rely on it when I need custom clothing or background details to stay exactly the same because those don’t always carry over properly.

The main thing is: don’t keep starting from zero if you already have something good. Get close with the generator, then use the other tools to finish the image.
